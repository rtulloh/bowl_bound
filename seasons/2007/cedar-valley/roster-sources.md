# Fictional sample roster

Created 2026-10-27 for Bowl Bound sample-team commentary testing. All names
were invented for this project; no historical roster, website, PDF, or real
player information was used. Any resemblance to real people is coincidental.
These original sample names are dedicated under CC0-1.0.

Positions are commentary labels only, not ratings or player-performance data.
The file uses the optional roster.json format documented in docs/rosters.md.
The engine uses these names only for illustrative commentary, never ratings
or individual-player statistics. Originally a local ignored fixture, this
exact fictional roster was approved for public tracking and release by the
owner on 2026-10-29 (DEV-042). No historical roster content is included.
