# Terminal play-by-play

Live reports and `log` display the same engine-generated announcer calls as
the web UI: runs, passes, scoring and supported kicks use varied, natural
sentences. Technical called-play/formation details and dice traces remain
separate. Kicks also retain their complete engine distance/result details.
Automatic kneels/spikes, pending decisions, penalties, unsupported results
and ambiguous recovery chains retain their factual engine wording.

Optional local rosters supply names; missing rosters/positions use generic
roles. **Names are illustrative commentary, not simulated individual-player
performance or statistics.** The explanation belongs here rather than being
repeated before every call. See [rosters](rosters.md) for setup and privacy.

Phrase and name choices are deterministic from the report number. Viewing
results/logs never consumes dice or coaching randomness. Loading a save uses
current installed rosters without altering saved semantic results, statistics
or future outcomes.
