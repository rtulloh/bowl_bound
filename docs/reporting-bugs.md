# Report a bug

Email **[bowlboundsupport@gmail.com](mailto:bowlboundsupport@gmail.com)**.
A short, reproducible report is more useful than a large unreviewed attachment.

## Please include

- A short description of the problem and what you expected instead.
- The **game version**: run `BowlBound.exe --version` on Windows or
  `./Bowl-Bound --version` on macOS/Linux; source users can use
  `python -m backend.launcher --version`. While the server runs,
  <http://127.0.0.1:8000/api/version> shows it too (adjust a custom port).
- Your operating system, processor type and standalone/source installation.
- Steps to reproduce; include control mode/difficulty and the game situation
  (teams, quarter, clock, down/distance) if relevant.
- Relevant **game logs**, startup/error messages or screenshots if available.
  The browser Play log and terminal `log` command are useful; persistent logs
  are not automatically written.
- Optionally, a reviewed save from a fictional-team game that reproduces it.

For an import failure, include the game/extractor version, the error message,
page number if reported, and a description of the layout—not the PDF or chart
contents. Reproduce with fictional teams or synthetic material where possible.

## Review before sending

Saves, logs, screenshots and dice/chart audits may reveal private chart values,
team/player information or local filenames. Send only material you have rights
to share. Do **not** attach source PDFs, historical chart bundles, full extraction
reports, credentials, personal information or unrelated files. Email is not a
secure document vault. A plain-text description without attachments is welcome.
Do not edit a save to remove fields: that can invalidate it. Instead omit it or
reproduce the issue with the fictional samples.
