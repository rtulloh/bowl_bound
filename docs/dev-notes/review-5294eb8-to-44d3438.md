## Ticket and test reconciliation

- **RULE-019/AI-021:** direct Advanced II results, physical defensive-die
  combinations, eligibility, and Option branch tests exist. Missing interactions
  include wrong numbered Wild Cards against Option runs, classification-changing
  penalty rerolls, invalid HTTP calls, and metadata propagation into season runs.
- **RULE-021:** tests cover box colors, fumbles, goal-line results and save/API
  integration. The yellow-box test uses a numeric token and misses penalty timing.
  The conditional-sneak test codifies a rule violation rather than detecting it.
- **RULE-028:** chooser ownership, selected cells, supplemental results, replay,
  and manual API paths are covered. Exact WCRZDZ tests omit down/possession
  assertions; the normal coached browser submission path is not exercised for
  either new identifier.
- **RULE-010/AI-016:** execution and penalty projections are tested independently,
  without asserting their equivalence on modified plays. This permits incorrect
  coach facts despite passing bounds and decision tests.
- **RULE-013/DEV-022:** the end-line correction and shared return refactoring
  retain different outcomes for a turnover return and a kick return at the same
  end-line coordinate. RULE-038 records this residual defect missed by the fix;
  it predates the review range in the special-team path.
- **AI-012:** tests check a field-goal estimate and a deterministic Hail Mary
  shortcut separately. They do not exercise the real selector when a late kick
  wins; one test requires Hail Mary while down one without assessing the kick.
- **DEV-052 and policy-version promises:** current-code round trips and historical
  digest fixtures do not establish compatibility with all real M21 states or
  preserved future choices. Actual baseline-generated saves expose both defects.
- **DEV-007/M32:** scheduling, completion, sums, malformed trace detection and
  failure continuation are tested. Per-period attribution, clock continuity,
  state transitions, and W-marked teams are missing. Zero fallbacks and a passing
  final score cannot establish these properties.
- **Documentation:** most affected player guides, schemas, version fields, and
  deferred-option decisions were updated. DEV-057 records remaining maintained
  contradictions; DEV-053/AI-023 record behavior that fails the documented save
  and policy compatibility contracts.

Changed assertion review found no newly added skips or xfails. Many replacements
are justified by added controls, v9 defaults, renamed metadata, or new structured
return facts. The contrary sneak expectation and incomplete selector/compatibility
oracles above need substantive correction, not relaxed assertions.
