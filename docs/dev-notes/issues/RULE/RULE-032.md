## Description

Advanced Rules III and IV add kickoff, punt, and return options beyond the basic special-team paths. The current engine implements only its approved basic procedures; each additional choice must be grounded in the Bowl Bound rulebook and remain unavailable until implemented.

## Resolution / verification

- Inventory each Advanced III/IV procedure and record its eligibility, dice/chart use, recovery or return path, field position, scoring, timing, and trace effects; create separate implementation tickets for adopted procedures and test them with synthetic charts.
