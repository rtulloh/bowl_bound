## Description

Final release review of verified run 40909408275 at e08542a found macOS artifacts bundle libssl.3.dylib, libcrypto.3.dylib and libncurses.6.dylib, but collected THIRD_PARTY texts contain no OpenSSL or ncurses notice. Windows bundles libssl-3.dll and libcrypto-3.dll, but its collected notices contain no OpenSSL notice either. Python and Python-package notices are not a complete native-library inventory. Hold public binary release; preserve existing artifacts as engineering evidence.

## Resolution / verification

- Inventory bundled native libraries and their exact versions/provenance on all three targets, including statically linked dependencies where applicable.
- Add verified upstream license/copyright/NOTICE texts and redistribution requirements to both portable payloads and Windows installer; test missing-notice rejection with synthetic fixtures before changing packaging behavior.
- Rebuild all three targets, rerun native/installer smoke and artifact checks, and complete fresh-machine and owner go/no-go acceptance before publishing.
