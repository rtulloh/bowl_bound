## Description

`tests/test_statistics.py` writes `game._charts` nine times and `tests/test_session_scoring.py:86`
once; `tests/test_overtime_extra.py:79,84` reads `_ot_profile`; `tests/test_save_game.py:297-310`
monkeypatches `game._engine.snap`; `tests/test_api_regulation.py:88` replaces
`RegulationGame.new`. These bypass public construction, exercise states the product cannot
reach, and break on internal renames. `tests/test_save_game.py:291-320` asserts
`not saved.wait(0.05)`, which passes on a slow machine even if the lock is broken.

## Resolution / verification

- Provide public or test-only seams (per-play chart cells via team_chart, an overtime profile
  on the view, a lock-acquired hook) and rewrite the affected tests to use them.
- Make the concurrency test deterministic: confirm the save thread is blocked on the lock
  before release, and that the save completes only after the command commits.
- Keep coverage and test counts from regressing.
