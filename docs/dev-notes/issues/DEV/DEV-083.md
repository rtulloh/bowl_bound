## Description

Both source jobs for candidate 2d330bc were cancelled at the 45-minute job limit (runs 42439578106 and 42439578999). GitHub annotations explicitly report exceeding 45m0s. Python coverage was still running, so frontend, chart audit and browser checks were skipped and native builds never started. The existing local full gate passed 5,543 tests in 2,581.90 seconds (about 43 minutes), leaving insufficient time for the rest of the job or hosted-runner variance.

## Resolution / verification

Use four development-only pytest-xdist workers with individual-case scheduling
and an explicit shared wheel-build group after file scheduling leaves the
expensive generator module serial. Reuse successful exact-commit main-push
validation before native builds; run dependency auditing as an independent
required job so failures report promptly without suppressing regression progress. Keep the shared
source limit at 240 minutes and native jobs at 45 minutes. Preserve every test,
combined branch coverage and its threshold, other gate commands, failure
propagation and publication separation. Update exact workflow contract assertions;
demonstrate their two expected failures before implementation, then run focused
and applicable full regression checks before pushing. Record measured hosted
completion and actual artifact checks before claiming upstream success. The
comments below preserve the earlier 120- and 240-minute serial proposals.
