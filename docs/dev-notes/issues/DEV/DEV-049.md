## Description

At ab4c70e, scripts/release_package.py:_manifest checks only that selected samples have hashes; it does not require the complete two-team allowlist. Reproduction used stage_sources to make a public-only source copy, removed seasons/2007/cedar-valley/special.csv from runtime and sample_sha256, then staged again, generated synthetic assets, assembled and archived. Every gate succeeded; /api/teams on the resulting library listed only Harbor Tech. The 27 packaging tests also intentionally use a single team.yaml with no complete playable bundle, so they cannot detect this regression. Hash consistency does not establish artifact completeness.

## Resolution / verification

- Require every mandatory file of both fictional teams, their provenance and sample license; require the agreed launcher/runtime/documentation essentials before accepting a release source manifest.
- Add tests that remove a required file from both the inventory and its hash map, rather than merely deleting an inventoried file. Missing team components must fail before output publication.
- Add an isolated real-resource smoke using only the public samples: list both teams, start a game, perform an engine action, save and load. Keep fast synthetic malformed-input tests as well.
- Preserve exact allowlisting and historical-data exclusions; do not repair incompleteness by recursively copying seasons or weakening hash checks.
