## Description

The released `v1.1.1` documentation and release notes still present native
downloads as the main entry point, while `main` leads with the hosted browser
edition. The owner directed that the browser become the preferred way to run the
game going forward, with native downloads retained as an optional offline path.

## Resolution / verification

- Present the hosted browser edition before native downloads in the README,
  player guide, installation, startup and playing guides.
- Keep native install, checksum, SmartScreen, quarantine and Windows terms
  guidance available and tested for players who need offline play.
- Add a documentation regression that requires the browser link and its
  recommended status to precede offline installation guidance.
- State the actual v1.1.2 catalog in player documentation: 179 generated teams
  across 1972, 2002 and 2007 plus the two fictional samples, for 181 playable
  teams. Derive the number from `release/manifest.json` in a regression rather
  than restating an earlier inventory estimate.
- Record the owner's reboot observation for the v1.1.1 Mac first-launch stall in
  DEV-093 without treating it as independently verified artifact acceptance.
