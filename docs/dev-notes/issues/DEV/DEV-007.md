## Description

Every complete-game test (tests/test_regulation.py, test_statistics.py, test_save_game.py and
frontend/e2e/web.spec.js) uses uniform synthetic charts where every cell is the same yardage,
so no full game under RandomDice exercises fumbles, penalties, options, QR/QT, variable
yardage or scoring returns together. Statistics reconciliation against the log exists only for
an all-zero-yardage game. The browser suite depends on request-side seed 7 plus uniform
charts for about a dozen literal string expectations, and `frontend/playwright.config.js:3`
defaults to a shared fixed temp path that is never cleaned.

## Resolution / verification

- Add seeded RandomDice full-game tests over synthetic charts with mixed legend cells,
  reconciling score ledger, quarter seconds, timing-log chaining, log length, traces and
  statistics invariants rather than literal values.
- Prefer API-view assertions over literal strings in e2e where practical; use a per-run
  temporary seasons directory under the approved temp root.
- Record the new simulations in the Milestone 23 gate.
