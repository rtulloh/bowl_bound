## Description

Imported college teams need a repeatable local-only season run that exercises the
production engine and coaching paths and leaves structured game logs for review. Each
readable team should receive twelve same-season matchups, with score, period, statistics,
clock, trace, and AI call evidence. Historical charts and detailed reports must remain
private and must not enter CI or release packages.

## Resolution / verification

- Add a local-only season runner for installed team bundles. Build deterministic
  twelve-game-per-team schedules separately within each chart season; use the production
  game/coaching paths and write detailed traces only under ignored `private-data/`.
- Reconcile scoring ledgers, period scores, report-derived statistics and regulation clock;
  retain coaching observations/calls and failure evidence, then continue later matchups.
- Cover schedule balance, stable seeds, audit failures and failure continuation with
  synthetic tests; never load historical charts in CI or package runner output.
