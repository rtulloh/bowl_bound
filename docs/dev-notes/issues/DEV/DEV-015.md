## Description

Owner requested Node 24.22.1 before alpha. The active frontend toolchain was
Node 18.20.8, end-of-life, with no project runtime pin or engines constraint.
Node's October 2026 security advisory explicitly covers the eMudhra intermediate
CA compromise. This is not evidence of an npm package compromise or host breach.

## Resolution / verification

- Pin Node 24.22.1, require patched Node 24/npm 11 for installs, document setup.
- Preserve the locked dependency graph unless incompatibilities require changes.
- Clean install and run existing frontend/unit/build/real-engine browser gates
  on Node 24.22.1; report warnings and dependency audit findings separately.
- Do not change global nvm defaults, rules, charts or application behavior.
