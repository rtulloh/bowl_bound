## Description

Twenty-four files, including `frontend/e2e/serve_backend.py:17-18`, import helpers from other
test modules (for example `from tests.test_models import provenance`, `from
tests.test_special_teams import special_chart, yards`, `from tests.test_penalties import chart,
foul`). There is no `tests/conftest.py` and only a handful of fixtures. Duplicated helpers have
drifted: two `foul`/`chart` pairs with different signatures (test_penalties vs
test_session_penalties), `provenance()` vs `evidence()`, two `metadata()` helpers and
inline reimplementations of the seasons/client fixtures across API tests.

## Resolution / verification

- Move synthetic chart, provenance, special-team, penalty and game-setup helpers into a
  tests support package or conftest fixtures; import only from there, including the e2e server.
- Remove drifted duplicates and keep behavior identical (test counts and results unchanged).
- Document the support layout in the tests section of AGENTS.md or docs.
