## Description

After alpha 4 was published, the owner reported that the repository release
sidebar still displayed alpha 3 with the Latest badge. The latest-release API
confirmed alpha 3. Alpha 3 was classified as a regular GitHub release; alpha 4
had been classified as a prerelease, excluding it from Latest selection.

## Resolution / verification

- Match the existing alpha-release convention by classifying alpha 4 as a regular
  GitHub release and explicitly selecting Latest. Its title, immutable tag and
  notes continue to identify alpha testing status and unsigned-build caveats.
- Do not rebuild, retag, replace assets or include Milestone 33/34 changes.
- Verify the latest-release API returns v0.1.0-alpha.4 and all 11 uploaded assets.
- Record the convention in the release note and run existing issue-index checks;
  no application behavior or artificial runtime regression test is needed.
