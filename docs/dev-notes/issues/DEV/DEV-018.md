## Description

Owner requires every reported problem to have an issue even when fixed during
the same work session. Recent UI work has tickets, but a tooling permission fix
was untracked and older save-download, special-label and opening-toss tickets
still say open despite committed fixes.

## Resolution / verification

- Make the always-track-immediate-fixes requirement explicit in AGENTS.md.
- Reconcile recent commits and owner reports with existing tickets; avoid
  duplicate tickets and invented fixes. Backfill missing reports.
- Resolve only tested committed fixes, preserving original report history and
  recording scope changes, exact checks and implementation commit references.
- Leave partial/unfixed requests open and retain play-test requirements for closure.
- Regenerate the issue index and run tests/test_issue_tracker.py.
