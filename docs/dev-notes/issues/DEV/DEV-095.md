## Description

On macOS the backend selects the real TMPDIR while conversion, halftime and history fixture subprocesses fall back to /tmp. Fourteen browser cases fail with synthetic TeamNotFoundError before UI assertions.

## Resolution / verification

- Use one fixture destination for backend and worker subprocesses, honoring explicit overrides and paths with spaces.
