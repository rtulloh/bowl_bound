## Description

docs/pdf-import.md:24-25 says the `tools` package is installed by the editable install only,
but pyproject.toml includes `tools*` in the wheel with the `bowl-bound-import` entry point
and tests/test_packaging.py asserts it ships. `tools` is also a generic top-level import name
that can collide with other distributions. The `web` extra installs FastAPI/uvicorn for a
`backend` package the wheel omits. .gitignore lacks `.coverage.*`, `coverage.xml`,
`frontend/coverage/` and `.mypy_cache/`. tests/test_packaging.py runs `pip wheel` on every
suite run (network-sensitive on clean machines).

## Resolution / verification

- Decide whether the importer ships; if so rename it (for example bowl_bound_tools or
  bowl_bound.tools) and update docs, entry point and tests; if not, exclude it and fix the doc.
- Document or remove the `web` extra; extend .gitignore; mark the wheel-build test as an
  explicit slow/packaging check in the gate.
