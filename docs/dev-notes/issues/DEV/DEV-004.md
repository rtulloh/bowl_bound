## Description

AGENTS.md requires the full regression gate before any push, but no script, Makefile, tox/nox
file or CI workflow runs it; README.md and docs/web-demo.md list the Python and frontend
commands separately. `frontend/playwright.config.js:24` serves `frontend/dist` without
building it, so a stale build can silently pass browser tests.

## Resolution / verification

- Add a documented script (for example scripts/gate.sh or a make target) that runs ruff check,
  ruff format --check, pytest --cov, vitest, vite build, then Playwright, failing fast and
  reporting skips/warnings.
- Make the browser step build first or fail when dist is older than sources.
- Point AGENTS.md, README.md and docs/web-demo.md at the single command; record it in the
  Milestone 23 review.
