## Description

The full frontend suite at ab4c70e passes 122 tests on the configured Node 24.22.1 toolchain but emits repeated "An update to App inside a test was not wrapped in act(...)" warnings, including coaching.test.jsx human offense/defense cases. These cases wait for an API spy call, which may happen before the response-driven rendering finishes; other coaching cases use raw timed waits. This weakens the test observation boundary and buries useful diagnostics. This review does not establish whether the warnings were introduced by the tooling upgrade or existed earlier.

## Resolution / verification

- Await the user-visible settled result of each asynchronous action; wrap explicit promise/timer completions in act as appropriate and clean up outstanding work.
- Run the affected cases alone and the full frontend suite with the pinned toolchain; require no React act warnings without mocking console.error, suppressing warnings or weakening assertions.
- Retain concealed-call, single-submit, serialized CPU action and save/load assertions; add delayed-response coverage if needed to demonstrate that the test waits for rendering rather than request dispatch alone.
