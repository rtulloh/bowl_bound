## Description

Public recipe inspection shows `_rare_tokens` inserts PI and interception families
into running-play columns and extreme negative total-roll distances into ordinary
defenses. Schema/coverage validation is not sufficient to establish realistic
playable charts. The owner requires common-sense play compatibility, including
no pass interference on ordinary running plays. No private play log is included.

## Resolution / verification

- Separate exhaustive stress-fixture coverage from normal playable sample data.
- Validate play/result compatibility for fictional samples, retaining legitimate
  called-versus-resolved Option passing branches.
- Test realistic loss bounds/distributions and audit full games rather than merely
  asserting completion or chart-family presence.
- Version changed recipe/provenance and regenerate only the exact public sample
  allowlist. Preserve historical charts and refuse broad seasons-tree writes.
- Explicitly address old-sample save replay compatibility before changing live
  sample bundles; do not replace charts underneath an active game.
