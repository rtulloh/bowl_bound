## Description

The actual 1.0.0 release staging check fails with Missing or invalid alpha version metadata because the package version parser only accepts alpha forms. Related runtime archive and Windows installer guards also require alpha versions. Support stable release identities while retaining metadata agreement, safe artifact naming and existing alpha behavior.

## Resolution / verification

- Write synthetic stable-version staging/runtime/archive and installer regressions first and demonstrate meaningful failures before production edits.
- Accept stable versions alongside existing alpha forms, preserve exact Python/display/frontend agreement and reject malformed or mismatched identities before creating outputs.
- Run focused release/native/installer tests, actual fresh 1.0.0 staging and the final full gate on the corrected committed source before push/build.
