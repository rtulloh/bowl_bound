## Description

The browser parsed save JSON and serialized it again for download. JavaScript
rounds integers larger than 2^53-1, changing a valid independent coaching seed
(or a large gameplay seed) and invalidating the integrity digest. The first
Milestone 20 Chrome gate reproduced this in the existing pending-interception
download/load test. Evidence uses synthetic teams only.

## Resolution / verification

Download successful saves as opaque response text and construct the Blob directly
from that text. Never parse or reserialize engine saves in the frontend. Preserve
error handling and load validation. Unit tests must preserve the synthetic integer
9223372036854775807 exactly; the real-engine browser download/refresh/load test
must restore the pending decision and identical future dice.
