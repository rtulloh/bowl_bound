## Description

Review of 5294eb8..44d3438 found an acceptance gap in `scripts/run_local_season.py:156-202`. validate_game checks each timing subtraction and the sum of reductions, but never checks that one interval starts where the previous one ended, that quarters reach zero in order, or that report state transitions are consistent. It also ignores report state_before/state_after entirely.

Synthetic reproduction: take `tests.test_local_season_runner.finished_view()` and replace each quarter's timing with two identical intervals (before=900, seconds=450, after=450). validate_game accepts all eight entries because they sum to 900 per quarter, even though every quarter rewinds to 15:00 and never reaches 0:00. The accepted finished_view fixture itself has no state fields, so no existing test can detect state continuity defects.

AGENTS.md and milestone 32 require reconciliation of state transitions and clock behavior, not merely a final flag and arithmetic totals. Assigned to milestone 23 as follow-up verification work.

## Resolution / verification

- Validate chronological clock continuity, legal quarter transitions and timing/play associations while allowing explicit zero-time and overtime events.
- Add adversarial tests for rewind, duplicate intervals, missing transitions, and inconsistent report field/down/possession continuity.
- Retain independent checks against engine reports; do not treat recomputing the same aggregate as full gameplay reconciliation.
