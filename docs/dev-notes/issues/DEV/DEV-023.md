## Description

save_game.ENGINE_PROFILE is bumped by convention; nothing derives it from rule modules. Divergent replays are caught by tape position and view digest, but a rule fix that changes an intermediate spot without changing dice count or the final view would replay silently.

## Resolution / verification

- Document the bump rule in docs/saves.md and add a checklist item or a test that fails when rule modules change without a profile bump, for example a hash of designated rule sources recorded alongside the profile.
