## Description

Prepare reproducible platform-specific PyInstaller standalone builds and GitHub Actions definitions without publishing or adding a remote. Depend on DEV-012 allowlisted staging, launcher and security remediation.

## Resolution / verification

- Stage only approved source/resource manifest; include built web UI, runtime dependencies, license and player documentation, never local charts or developer files.
- Build exactly three initial targets: macOS Apple Silicon arm64, Windows x64 (BowlBound.exe), and macOS Intel x86_64. Require native build/smoke evidence before claiming support. Linux standalone builds are out of initial scope.
- Validate version/tag identity, produce SHA256 checksums and inspected artifact manifests; publication remains a separate explicit approval, with no automatic public release during preparation.
