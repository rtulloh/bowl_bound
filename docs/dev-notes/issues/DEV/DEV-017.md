## Description

The legacy bash allowlist already permits npm test and npm run build, but the
OpenCode V2 shell permissions do not. Owner requested allowing these routine
validation commands, including the explicit pinned Node 24.22.1 PATH prefix.
The owner also requested npx playwright test with private temporary fixture folders.

## Resolution / verification

Add exact and argument-bearing V2 shell rules for both commands and their Node
24.22.1-prefixed forms in opencode.json. Allow Playwright test with the current
Node/E2E environment prefixes and external_directory access only to the trusted
agent temporary workspace, not all private folders. Preserve
all unrelated permissions and Git push/destructive-command denials. Validate
JSON; run the frontend test suite and production build using the pinned runtime.
This is configuration-only work,
so no artificial gameplay regression is required.
