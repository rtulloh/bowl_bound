## Description

Owner requested a less verbose documentation set during the 2026-10-30 review. Current docs/installation.md (126 lines), startup.md (42), importing-teams.md (191) and python-setup.md (91) repeat startup/setup and distribute the first-run path across several pages. Installation puts long platform security troubleshooting before source setup; the team-import guide leads with page dimensions, rotated headers, vector geometry and provenance internals before the actual commands. These details are useful references but slow ordinary players trying to install, play and save.

## Resolution / verification

- Make the README/player index lead to one short download/extract/launch/start-game/save-and-stop path. Keep a brief unreleased status until downloads exist and retain the two fictional teams and no-autosave facts.
- Give each topic one canonical home: installation for first launch, playing for game controls, troubleshooting for failures. Replace repeated explanations with links.
- Move source setup and the optional extractor to clearly labeled advanced guides; retain all owner-requested Windows/macOS/Homebrew/pip instructions and platform-specific download verification/security help there or in troubleshooting.
- Move exact PDF geometry, metadata/provenance schema and developer validation details into the technical importer reference; keep a concise supported-PDF checklist and working platform commands in the player import walkthrough.
- Review the shortened path as a new standalone player and separately run the source/import examples using synthetic materials. Keep packaged documentation links valid when reference pages move.
