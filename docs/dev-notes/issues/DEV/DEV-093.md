## Description

Published macOS downloads provide only portable ZIPs. A browser-extracted archive is named BowlBound, but installation guidance names a versioned folder. Nested quarantined Python fails dlopen with library load disallowed by system policy. A macOS app/DMG and validated actual extracted-folder instructions are required.

## Resolution / verification

- Build both supported macOS architectures as DMGs containing a Finder launcher and exact verified portable resources.
- Reproduce downloaded bytes, verify copied ZIP launch after narrow recursive quarantine removal, and smoke a mounted/copied local DMG app.
- Retain immutable v1.1.0 and disclose signing and native platform validation gaps.
