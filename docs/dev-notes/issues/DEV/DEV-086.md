## Description

The latest upstream Tests run on main at
`e218fd95942eecbd1f82b50111718b6c996d1a0a` fails because the exact release
frontend allowlist omits two newly imported components:

- `frontend/src/App.jsx` imports `./components/CatalogProblems`.
- `frontend/src/components/MatchupBuilder.jsx` imports `./TeamPicker`.

Both JSX files exist in the checkout but are absent from the `frontend` list
in `release/manifest.json`. `stage_sources` copies only manifest entries, so
the staged frontend cannot resolve these imports. A normal checkout frontend
build does not validate this isolated release tree.

Evidence: [Tests run 43878918773, job 133339235118](https://github.com/rtulloh/bowl_bound/actions/runs/43878918773/job/133339235118),
created 2026-11-16 13:45:54 UTC. At 15:12:42 UTC,
`test_real_staged_frontend_contains_every_local_import` reports both unresolved
imports. Final result: **1 failed, 5,608 passed**, 92.21% coverage, 5,178.89
seconds. This is an assertion failure, not the older DEV-083 timeout failure.
