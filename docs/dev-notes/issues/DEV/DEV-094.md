## Description

A Finder-started app remains alive after smoke ownership identification fails. TemporaryDirectory cleanup deletes its copied payload while the UI continues serving from the old process, producing unavailable team folders and eventually an empty catalog. Preserve failed native evidence and resource copies until safe shutdown rather than creating misleading packaging failures.

## Resolution / verification

- Write a synthetic failing Finder-path smoke and prove its copied resources remain available after failure.
- Preserve separate native failure evidence without signaling an unidentified or foreign process.
- Require a fresh native app run with complete catalog and no problems before qualification.
