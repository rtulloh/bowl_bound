## Description

The two pre-M27 save fixtures contain python=[3,12], while the standalone workflow runs Python 3.13.17 and the save contract deliberately rejects different Python major/minor versions. The upstream test job therefore rejects these fixtures before legacy digest replay; local Python 3.12 tests pass. Keep production cross-runtime rejection and make legacy-digest tests runtime-neutral.

## Resolution / verification

- Before the fix, both tests failed under Python 3.13.1 at the runtime compatibility check.
- Adapt only fixture Python metadata to the active interpreter and recompute integrity; preserve old commands, dice, engine profile, and state digests.
- Add a test proving an actual save with a mismatched Python major/minor remains rejected.
- Tested commit: `0f4eab9`.
- Upstream workflow [41203334774](https://github.com/rtulloh/bowl_bound/actions/runs/41203334774) passed on Python 3.13.17: 2,607 tests at 93.27% coverage, frontend tests/build/audit, 33 browser tests, and all three platform builds.
