## Description

During the owner-requested Node 24.22.1 upgrade, `npm audit` reports five
vulnerable package entries: two moderate, one high, two critical. The exact
380-entry locked dependency graph predates the runtime upgrade and is unchanged.
Affected tooling chain: esbuild, Vite, vite-node, tinypool and Vitest.

`npm audit --omit=dev` reports zero vulnerabilities. This narrows the current
advisory scope, not a claim that development/CI exposure is harmless or that
compiled assets have had a comprehensive security audit. No evidence of host
compromise was found or claimed; this is separate from the eMudhra CA incident.

## Resolution / verification

- Treat as a pre-alpha dependency-remediation task.
- Review advisory applicability and select supported, patched Vite/Vitest and
  compatible plugins/test tooling deliberately; do not run blind force fixes.
- Preserve all gameplay/no-client-rules assertions, save continuation and
  real-engine browser acceptance. Run clean install, unit tests, build,
  dependency audit and full browser gate on pinned Node 24.22.1.
- Document remaining findings, deprecations and lifecycle-script policy.
