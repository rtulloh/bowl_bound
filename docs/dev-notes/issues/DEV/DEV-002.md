## Description

`bowl_bound/save_game.py:247-253` sets `self._engine._dice` and `self._engine._session._dice`
directly because `PlaySession.new` and `RegulationGame.new` have no shared dice-source
argument for every roll path. `regulation.py:87,96` also seeds two independent `Random(seed)`
streams (session and regulation) that are identical; the session stream is dead in regulation
mode but live in drive mode, which makes future AI/determinism audits confusing.

## Resolution / verification

- Add a `dice=` constructor argument to both engines that is used by every roll path,
  including overtime tosses and pending procedures, with tests proving one shared stream.
- Replace private attribute assignment in save_game with the constructor argument; keep the
  seeded-equivalence save tests green.
- Document the dice-source contract in docs/dice.md.
