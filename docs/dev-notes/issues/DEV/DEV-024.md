## Description

cli.TeamCatalog and backend.app._team_folders/_load implement team discovery separately; the CLI version does not skip provenance folders or require canonical folder names. The team id regex is defined in cli.py, backend/app.py and save_game.py. backend/request_limits already bounds /api/games/load so the streaming loop in app.py cannot trip. coach_step returns the private CoachChoice as a fourth tuple element every caller must drop. The backend module docstring still says Milestone 10 demonstration.

## Resolution / verification

- Added `bowl_bound.team_catalog` for canonical team discovery and loading; both CLI and API now use its folder and provenance filtering. Save validation and API input validation share the team-ID expression and maximum length.
- Removed the API load route's duplicate streaming size loop; `RequestBodyLimit` remains the single bounded body reader. `SavedGame.coach_step` exposes the report, view and next turn; private `CoachChoice` remains internal. Updated callers and the stale backend docstring.
- Verified at `2c29951`: 374 CLI, API, catalog, save-game, and coaching-contract tests passed. Ruff check/format passed.
