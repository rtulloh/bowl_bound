## Description

Bowl Bound currently exposes one manual workflow named Build standalone apps. This makes ordinary regression status invisible after a push and does not say that the long-running workflow produces release executables. Provide separate, plainly named workflows modeled on the local Paydirt repository: an automatic Tests workflow for push/PR validation and a manual/tag-appropriate Build and Release Standalone Executables workflow for packaging.

## Resolution / verification

- A push to main creates a Tests run with the project regression gate and a clear commit association.
- The standalone packaging workflow is labeled Build and Release Standalone Executables, preserves its explicit release/build controls, and can be dispatched for a specified main commit.
- Workflow tests or static validation cover triggers, required permissions, artifact/release behavior, and failure propagation; documentation tells maintainers which workflow to use.
