## Description

Owner requested proceeding to the next roadmap milestone after the web follow-up.
Milestone 20a terminal play is still pending and precedes chart-aware coaching
in 21. No playable terminal launcher currently exists.

## Resolution / verification

- Standalone python -m bowl_bound and bowl-bound launchers, public-sample defaults,
  local team discovery, regular/postseason, human home/away and two-sided manual.
- Reuse SavedGame and its public coaching methods; do not inspect hidden plans,
  implement football rules, change engine/save formats or depend on web/Paydirt.
- Render engine state/status, legal actions/choices, reports, statistics and optional
  recorded traces; inspection and invalid inputs consume no dice.
- Advance automatic turns only after gameplay/start/resume, stop on human decisions
  and errors, and require explicit retry after automatic failure/loop guard.
- Private create-only saves (0600); bounded codec-compatible loads replace the
  current game only after complete validation. EOF/interrupt/quit do not decide.
- Test-first synthetic coverage, complete-game reconciliation, hidden-call privacy,
  direct engine/API continuation parity, docs and focused/cumulative gates.
