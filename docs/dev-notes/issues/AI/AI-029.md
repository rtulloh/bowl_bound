## Description

In a normal CPU possession, the offense selected QB Sneak on third-and-long. The current Medium random pool classifies every offered non-run as a passing-down candidate, which lets the short-yardage QB Sneak receive the same probability as ordinary passes. Coaching must restrict QB Sneak to appropriate short-yardage or explicitly documented late-game situations.

## Resolution / verification

- Synthetic coaching tests reject QB Sneak as a preferred CPU call on ordinary third-and-long situations unless an explicitly documented late-game exception applies.
- The selected CPU action remains legal and deterministic under fixed seeds, with a test for a short-yardage situation where QB Sneak remains eligible.
