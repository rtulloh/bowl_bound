## Description

The initial Bowl Bound fourth-down policy uses shared, public field-goal-distance
bands. Kicking range has changed over time, and college kickers are not equally
reliable. Decide whether a future Bowl Bound season/team coaching setting should
adjust the public attempt-distance policy. It must be explicit to players and
available to both human guidance and AI selection; it must not infer a hidden
advantage from chart data. Paydirt's unused season aggression setting and 1983
NFL thresholds are design input only, not a rule source.

## Resolution / verification

- Document a Bowl Bound-specific source and schema for a public season/team
  attempt-distance adjustment, or explicitly retain the shared range policy.
- If adopted, expose the same setting in human coaching guidance and AI selection.
- Synthetic tests show it changes only documented fourth-down calls; it never
  changes engine rules, dice odds, or chart resolution.
- If deferred, retain the shared range policy without dormant configuration.
