## Description

All policies kneel when leading with 60 seconds or less in the fourth quarter on downs 1-3 without checking whether the opponent's timeouts or remaining downs allow the clock to run out, so the computer can kneel into a punt or lose the ball on downs. BaselineCoach.decision also lacks the overtime guard present in offense. Paydirt exposes can_kneel_out_game from the engine and the AI only asks it, matching the engine-is-source-of-truth rule.

## Resolution / verification

- Engine exposes a kneel-out query using Bowl Bound timing, downs, opponent timeouts, score and safety risk; v2 policies consult it. New CLI/API games use v2; prior policy versions and saved-game behavior remain unchanged.
- Synthetic boundary tests cover both sides, timing after a pending play, timeout choices, downs, own-goal safety, overtime, ties and trailing. A real regulation test verifies a kneel and timeout ending the game.
