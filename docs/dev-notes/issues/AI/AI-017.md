## Description

The report said that `coaching_session._observation`'s legal-choice filter removed disabled choices from a human's coached pending decision. In the current implementation, that filter is used for computer policy observations; human-owned non-clock decisions return the engine's pending choice tuple directly. The reported mandatory two-point overtime case already preserves the disabled kick and engine reason. The clock-choice path intentionally filters choices to the human's permitted clock controls.

## Resolution / verification

- Coached human decisions preserve the full engine choice tuple, including disabled flags and reasons; execution remains restricted to enabled IDs. Cover the mandatory-two overtime decision with a regression test and retain CLI/browser rendering checks.
