## Description

coaching_session._observation keeps only enabled choices and plan_turn rebuilds the human's pending from that allowlist. In a synthetic overtime round requiring a two-point try the engine offers conversion:kick disabled with a reason, but the coached turn shows only conversion:two. Manual browser mode shows the disabled button and reason; coached mode in CLI and browser never does, so docs/cli.md's statement that disabled choices include the reason is false for the only CLI mode. The CLI unavailable-reason rendering is reachable only by monkeypatching.

## Resolution / verification

- Coached turns preserve the full engine choice tuple with enabled flags and reasons, filtering only the opponent's timeout entries; execution remains restricted to enabled ids. Test: plan_turn on the mandatory-two state returns the disabled kick with its reason; CLI and browser render it.
