## Description

Review of 5294eb8..44d3438 reproduced contradictory penalty previews in `bowl_bound/session.py`. `_pending_view` projects `prepared.resolution` before `_apply_live_result` applies `_apply_bounds_declaration` and conditional-defense doubling. A decline therefore has different first-down, scoring, possession and field results from the engine facts supplied to v8/v9 coaches.

Synthetic reproduction with existing helpers: create `tests.test_bounds_declarations._penalty_session()`, call `snap("1", "A", dice=_penalty_dice(), bounds_declaration="out_of_bounds")`, and inspect the decline DecisionOutcome. It predicts first-and-10 at yards_to_goal=53 (12-yard gain). Executing `decide("decline")` yields second-and-3 at yards_to_goal=58 (7-yard gain). On fourth down this can invert who retains possession. Conditional Wild Card/Run/Pass doubling is likewise applied only after projection.

AI-016 claims projections use the same transitions as execution; the v8 tests cover only unmodified plays, while bounds tests assert execution without comparing projections. Assigned to milestone 23 as a follow-up to committed milestone 22.

## Resolution / verification

- Compute decline projections and labels from the same fully adjusted result that execution uses, without consuming dice.
- Add synthetic equivalence tests across ordinary/conditional defenses, bounds declarations, first downs, fourth downs and scoring boundaries.
- Assert the coach chooses from accurate outcomes, and preserve penalty-acceptance rules separately.
