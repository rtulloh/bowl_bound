## Description

BaselineCoach.decision always fair-catches punts, always takes touchbacks, never returns a kick or declines a penalty, and penalty and kickoff out-of-bounds choices fall to the first offered choice. Every decision sets fallback=True, diluting the diagnostic. baseline-v1 is frozen for legacy saves, so changes need a new version and tiers should inherit improved decisions.

## Resolution / verification

- Difficulty tiers get versioned decision preferences covering kick returns, penalty decline and spot choices with engine constraints; fallback is reserved for safe_choice recoveries. Tests cover each pending family on both sides. Legacy baseline-v1 behavior unchanged.
