## Description

BaselineCoach.decision always fair-catches punts, always takes touchbacks, never returns a kick or declines a penalty, and kickoff out-of-bounds choices fall to the first offered choice. The broad claim that every decision sets fallback=True is not reproduced for valid baseline choices; however, a Hard chart-analysis fallback can remain set and incorrectly mark a later legal decision. baseline-v1 is frozen for legacy saves, so changes need a new version and tiers should inherit improved decisions.

## Resolution / verification

- Difficulty tiers get versioned decision preferences covering kick returns, penalty decline and spot choices with engine constraints; fallback is reserved for safe_choice recoveries. Tests cover each pending family on both sides. Legacy baseline-v1 behavior unchanged.
- AI-016 completed in `7f73978`. The engine now projects deterministic legal penalty outcomes with pure rule transitions; it marks turnover chains that need another roll as unresolved. Coaching v8 uses these structured facts and falls back to its prior choice order when outcomes tie or remain unresolved. Prior policy versions omit the new observation field from their RNG inputs, and save-view digests ignore this derived presentation data.
- Test-first evidence: the new 18-case v8 suite failed against the unchanged implementation because v8 and projected outcomes did not exist. Focused validation then passed: 181 Python tests; Ruff lint and formatting; `git diff --check`; 32 public-sample full games across both team arrangements and CPU sides, with all games finished, 32/32 save continuations verified, and zero illegal selections. Two reported analysis fallbacks were legal tight-red-zone fallbacks, not stale decision flags.
- Follow-up `6024e5f` aligns the CLI default-policy test with Hard v8 while retaining the `chart-v1` save-resume expectation. Verified with the focused test and Ruff check/format.
- Awaiting owner play-test before closure.
