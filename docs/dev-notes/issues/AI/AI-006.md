## Description

coaching_evaluation.evaluate_action snaps hail_mary with 9/A while regulation uses 8/A, and the sampled opposing call is drawn and discarded so the mixture docstring is false for that candidate. turnover_rate is really possession-lost (punts and kickoffs count 1.0). except ValueError also swallows programming errors in the sandbox and reports them as failed samples, hiding bugs behind whole-comparison fallback. getattr(observation, 'hurried', False) guards a declared dataclass field.

## Resolution / verification

- Hail mary analysis matches regulation; opposing call is not drawn when unused. Rename or document turnover_rate as possession lost and update audit consumers. Only EvaluationError and engine-declared rule errors count as failed samples; other exceptions propagate. Remove the getattr guards. Tests cover each change.
