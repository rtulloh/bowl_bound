## Description

GameAudit.save_continuation_verified and illegal_selections are hard-coded constants, so the test asserting illegal_selections == 0 is tautological. The stand-in human is given empty special and game_actions on fourth down, so audited games have a human who never punts or kicks, which distorts scores and the committed-call frequencies Hard learns from. Step 40 is a magic constant. Paydirt's audit also records the normalized probability vector per call, groups by situation band with largest share, distinct plays, longest comparable streak and small-sample flags, emits an advisory concentration warning, redacts exception text, derives per-game seeds by hash, exports JSON/CSV and validates that period scores and the scoring ledger sum to the final.

## Resolution / verification

- Evidence fields are derived from observed behavior, including a test proving a mismatch fails. Stand-in may punt or kick on fourth down. Add per-call preference vectors, situation-band concentration summary with advisory warning, period-score and ledger reconciliation, no kickoff after game over, redacted error text and a documented runner command with JSON output. Update docs/dev-notes/coaching-audit-m21.md.
