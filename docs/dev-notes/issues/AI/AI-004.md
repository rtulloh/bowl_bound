## Description

CoachObservation carries no phase and PlaySession.for_analysis always starts in SCRIMMAGE, so a conversion try looks to Hard like 1st-and-2 at the 2. A try play is valued with 6-point touchdowns and a failed try appears to retain possession at 2nd-and-goal. The same observation is produced for a real 1st-and-goal from the 2, so cached estimates conflate the two. Both the Hard offense choosing the try play and the Hard defense defending it are affected.

## Resolution / verification

- Observation exposes the try/series phase and the evaluator uses it. Test: an observation built from a real pending conversion:two state values success at 2 points and failure as the end of the try with no retained possession. Test: cache keys differ between a try and a 1st-and-goal from the same spot. Test: overtime series candidate evaluation completes without running a kickoff.
