## Description

Run probability depends only on down and distance; on third or fourth and more than 3, every tier uses 0.25 so aggression has no effect and docs claiming Easy is conservative are not accurate there. Trailing by two scores with four minutes left produces the same mixture as a tied first quarter. Paydirt uses a bounded pressure factor from scores needed over minutes left that never zero-weights runs, and the mirror run tilt when protecting a lead.

## Resolution / verification

- Mixture varies smoothly with deficit and time, bounded, with runs retaining a floor and the full nine calls remaining possible; lead protection tilts toward runs late. Tests: pass share increases as time shrinks and deficit grows; a full comeback quarter keeps at least seven distinct plays; aggression changes passing-down mixtures. docs/coaching.md updated.
- Ship as v4 policies so v1–v3 saved selections remain unchanged; update API/CLI defaults, save validation, audits, and user documentation together.
- Implemented and verified at `a04288b`; earlier policy streams remain frozen. Resolved pending owner play-test; not closed.
