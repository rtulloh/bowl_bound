- Preserve physical dice distributions and clearly distinguish sampled estimates from exact probabilities; preserve priorities, turnover/fumble/penalty/sack/Option/QR/QT continuations, public-information rules and preview purity.
- If a fix is justified, write meaningful failing synthetic regressions first; preserve frozen coaching/save compatibility and validate focused/relevant engine/API/CLI/coaching regressions with documentation and tested commits.
