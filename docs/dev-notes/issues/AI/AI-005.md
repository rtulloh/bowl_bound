## Description

SavedGame.snap advances the engine and consumes dice, then calls the policy's commit_call, then appends the command journal. If commit_call ever raised (it validates play 1-9, defense A-F and non-None state) the engine would have advanced with no journal entry and the save would no longer replay. Unreachable today only because the engine validates the same inputs first.

## Resolution / verification

- Journal the command before or atomically with policy history updates, or make commit_call unable to abort. Test: monkeypatch commit_call to raise and assert either the command is journaled or the engine state and tape are unchanged.
