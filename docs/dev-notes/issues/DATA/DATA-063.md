## Description

The owner requests a defensible formula for optional defensive (B) placement rather than automatically assigning it to every team or formation. This is a proposed generation-model refinement; no chart or engine behavior change is made by this issue.

## Resolution / verification

- Analyze available authorized references and source explosive-play susceptibility, including Screen as well as running calls; separate observed support from authored assumptions.
- Define when a team/call/formation qualifies, and preserve unknown conditional evidence instead of inventing support.
- Prefer rare physical dice exposure where justified. Treat usually zero to two cells as a working expectation, not a universal cap or mandatory allocation; evaluate documented reference exceptions.
- Evaluate actual Priority and supplemental outcomes, weighted event mass, tail, mean, turnover and sideline effects; cell count alone is not probability.
- Present a simple documented algorithm, alternatives, sensitivity and source limitations for review before implementing it.
- After model approval, add failing synthetic controls first and regenerate LSU/Ohio State for visual and quantitative review before any broader regeneration.
- Do not require exact developer-chart replication, cosmetically add (B), or delay the already accepted experimental release.
