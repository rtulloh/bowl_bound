## Description

Owner requested a visible web halftime transition. Implement the browser counterpart to CLI-058 in the same milestone, using shared engine-owned halftime facts. The transition must remain visible and reviewable even when the computer owns the scheduled second-half kickoff.

## Resolution / verification

- Show a distinct halftime transition and first-half recap before the second-half kickoff, including automatic computer-owned kickoff paths.
- Use shared engine/API facts for quarter scores, first-half scoring events, available statistics and kickoff assignment; do not infer football behavior from prose or quarter display in the browser.
- Cover ordinary period end, end-of-half scoring, outstanding PAT/penalty/other decisions, both human sides, manual mode, new games and save/resume without duplicate or skipped transitions.
- Do not consume game time or dice, change halftime kickoff ownership, or let automatic actions immediately overwrite the transition before it can be reviewed.
- Test first with synthetic engine/API/frontend/real-engine browser cases; record tested commits and owner play-test confirmation before closing.
