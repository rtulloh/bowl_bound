## Description

The user cannot identify each die’s color from the current face-only trace and
recalls Paydirt displaying that identity. Bowl Bound uses black/white/white
offensive dice and red/green defensive dice, with different face distributions.
A total alone does not explain the real roll.

## Resolution / verification

Present die colors, individual faces, and the engine-supplied total consistently
for human and computer actions. The engine supplies role/color metadata; the UI
does not infer die types from chart prose. Distinguish the two white dice and
provide text/accessible labels rather than relying on color alone. Preserve
actual observed roll order, including supplemental, toss and recovery rolls.
Synthetic frontend and real-engine browser checks must cover both dice sets and
confirm presentation changes never consume or reconstruct gameplay rolls.
Review Paydirt only for design ideas, not NFL dice assumptions.
