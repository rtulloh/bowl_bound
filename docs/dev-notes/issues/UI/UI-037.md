## Description

The modifier-row Spike button is always disabled with an available-when-offered tooltip, but when the engine offers clock:spike the clock-choice panel replaces the row, so it can never enable; docs/web-demo.md and docs/coaching.md describe it as a one-shot control. The 'timeout:home'/'timeout:away' label map is unreachable because timeouts are filtered earlier. Minor UI-side derivations also remain: defense panel name from possession, an invented 0-0 score default, positional timeouts[0]/[1].

## Resolution / verification

- Removed the permanently disabled Spike button; the engine-offered clock choice is the only Spike control. Removed unreachable timeout labels from the extra-play map.
- Added engine-provided `defense_name`, `home_timeouts` and `away_timeouts`; the browser uses these fields and the explicit score, with an em dash for a missing score instead of inventing 0–0.
- Updated coaching, demo and API docs. New frontend tests first failed on all six targeted cases before the implementation.
- Verification at `bde4f40`: frontend component/clock/modifier tests under Node 24 (33 passed); `.venv/bin/python -m pytest tests/test_regulation.py tests/test_api_regulation.py tests/test_save_game.py -q` (99 passed); Ruff check/format and `git diff --check` passed.
