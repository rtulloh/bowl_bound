## Description

Team selection includes seasons, but the engine session exposes bare team names
for the scoreboard, possession, decisions, results, and traces. Bowl Bound allows
mixed-season games, so a school name alone is not a complete team identity.
Same-school matchups across different years must remain distinguishable.

## Resolution / verification

Provide consistent engine-owned season-qualified display names (for example,
2001 Alpha Tech versus 2003 Alpha Tech) across scoreboard, possession, selectors,
pending decisions, reports, scoring ledger, traces, and play log. Keep stable team
IDs and designated home-season rules selection independent of display labels.
Cover mixed years, same school across years, same-season opponents, and mirror
matches in synthetic session/API/frontend tests and a real-engine browser check.
Do not make the browser infer identity or rules from formatted name text.
