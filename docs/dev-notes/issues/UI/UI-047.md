## Description

The web sidebar presents the persistent Hurry-Up preference while the human player is defending, even though only the acting offense can request that clock behavior. When the computer offense uses hurry-up, the player instead needs an engine-owned commentary indication.

## Resolution / verification

- Show the persistent Hurry-Up control only when the human controls the offense, while preserving manual two-sided play.
- Ensure a computer-selected hurry-up is represented by engine commentary or an engine-owned presentation fact, not UI inference.
- Add focused UI and engine/commentary coverage, then verify frontend and relevant Python tests.
