## Description

Owner play-testing requested removal of the routine Pause/Resume control, the
in-game human/computer mode selector and Snap button. New game, Save and Load
occupy play-area space and force additional scrolling. Paydirt is the interaction
reference; Bowl Bound must retain its own engine and saves. A later owner
screenshot also requested legal specials alongside ordinary calls, with a large
number/letter above a short name (P/Punt, K/Kneel, F/FG). Q/Sneak is unsupported
and must not be enabled by a presentation change.

## Resolution / verification

- Choose human/computer mode on setup only. A human call immediately submits
  against the concealed computer call; manual play submits on the second fresh
  selection, in either order. Clear both calls on submission, including failures.
- Keep required decisions, final-state blocks and serialized automatic turns.
  Show Retry computer only after automatic failure or the existing safety guard.
  Saving a stopped game must not silently restart failed automatic requests.
- Put New game, Save and Load in a collapsed, keyboard-accessible header menu
  whose overlay does not push the playing controls down. Retain setup loading.
- Loads retain the explicitly selected browser mode (manual by default), not a
  mode from the save. Failure to prepare controlled views leaves the old game
  intact; saves remain opaque and exact.
- Synthetic unit tests first failed against the unchanged UI: 12 failed / 3 passed
  for compact controls, immediate submission, retry and load controls. A further
  save-after-automatic-error regression reproduced an unintended silent retry.
- Existing browser checks now select fresh calls instead of clicking Snap.
  They retain score/clock/statistics/dice/save assertions, and assert disabled
  play controls after final rather than a disabled removed button. The first
  browser rerun passed all six complete sample games and 14 other checks; two
  pending-interception checks expected a disabled offensive button when the
  engine actually offers no offensive calls. They now assert the required choice
  and zero enabled offensive/defensive controls, retaining all timing, save and
  future-dice assertions.
- A separate failing unit test verifies that offered kicks/kneels are inside the
  ordinary play panel, show the requested abbreviations/names and dispatch their
  existing engine endpoints without a defensive call. A second failing assertion
  verifies FG shorthand with the full engine label retained accessibly.
- Final totals and commit evidence pending; keep open until tested and committed.
