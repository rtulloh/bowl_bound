## Description

The user sees field_goal on the field-goal control. The shared selector renders
raw action keys alongside labels, leaking an API identifier into player-facing
text. Words should be separated by spaces, not underscores.

## Resolution / verification

Render the Punt and Field Goal buttons as one line each, exactly Punt and Field
Goal, without a raw identifier or redundant subtitle. Provide display labels in
the engine and keep punt / field_goal as stable API keys. Review other special-team
controls for duplicate wording without removing useful distinct explanations. Keep
meaningful play numbers and defensive letter references where helpful. Add frontend
coverage for exact visible labels and unchanged submitted action keys, then verify
the controls in the browser.
