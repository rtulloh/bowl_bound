## Description

The synthetic review showed only a generic special-teams-pending result before a touchback/return choice. The user independently reported not knowing where the kickoff landed. Synthetic reproduction: a kickoff from own 35 traveling 68 yards lands three yards deep in the receiving end zone.

## Resolution / verification

Implemented and tested in `57b4dd6`. Engine kick descriptions supply origin, named teams, flight distance, landing/depth, return distance and resulting spot. Synthetic tests cover in-field/end-zone/beyond-end-line kicks, punts and field goals; raw evidence is expandable.

See [Milestone 19 acceptance](../../milestone-19.md) for the cumulative gates
and changed expectations. The committed implementation was rechecked with 99
focused Python tests. Awaiting owner play-test confirmation before closure.

Have the engine describe kicking/receiving teams, kick distance, landing spot or end-zone depth, and the next required choice before prompting. Also improve completed kick/return summaries. Test in-field, end-zone, and beyond-end-line kicks with synthetic charts. The UI must display engine facts, never calculate the landing spot from raw cells or dice.
