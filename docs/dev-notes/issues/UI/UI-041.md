## Description

The CPU formerly estimated a kicker's chart make distribution when choosing a
fourth-down field goal, while a human player received no equivalent decision
support. The owner selected a shared visible fourth-down policy for normal play.
Milestone 33 supplies read-only player guidance under that same policy. Future
public season/team range settings remain AI-031 scope; neither may recreate
hidden chart-aware CPU selection.

## Resolution / verification

- Confirm the shared public policy remains the normal-play basis, or document a
  replacement with equal player visibility.
- If a player estimate is adopted, it is engine-derived, read-only, and displayed only when the player can legally choose a field goal or punt.
- Synthetic tests prove the UI/API do not calculate independent chart behavior and that normal player and CPU decision support follows the approved policy.
