## Description

A local server restart clears its in-memory games. A browser tab that still holds the prior game ID reports the raw API error 'no such game' when the player next selects a call, making the play button appear broken.

## Resolution / verification

- Translate the stale-game 404 into an actionable explanation that the local server was restarted and the unsaved game cannot be recovered.
- Offer an accessible New game action from the error state without falsely claiming the game was saved or restored.
- Add frontend regression coverage for the stale-game error path.
