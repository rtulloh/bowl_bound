## Description

The engine supplies Formation A, Formation B, and so on for all six defensive
choices. The user cannot tell which is standard, short-yardage, or another tactical
formation without outside reference. The synthetic browser review also showed
these opaque labels.

## Resolution / verification

Verify the official Bowl Bound names and A–F mapping before changing labels; do not
guess from Paydirt or generic football terminology. Supply meaningful names and
short tactical explanations from the engine, retaining letter keys for chart
reference. Present them consistently in selectors, selected-action feedback,
results, and trace labels. Synthetic session/API/frontend tests must assert the
verified mapping; a browser play-test must show that all six choices are useful to
a new player without requiring chart knowledge. This is naming/presentation work,
not a change to defensive dice distributions or chart lookup.
