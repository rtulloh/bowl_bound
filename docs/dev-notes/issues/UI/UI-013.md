## Description

Hurry-up currently applies to only the next snap and must be selected again
for later plays. The user wants a persistent on/off mode, like Paydirt’s
no-huddle interaction, rather than a one-shot clock decision.

## Resolution / verification

- Provide an accessible hurry-up toggle, off by default, with a visible mode
  indicator. Once enabled, it remains enabled across successive eligible plays
  until switched off; ordinary play requires no repeated hurry-up selection.
- Keep mode state, eligibility, timing and hurried penalty handling in the engine.
  The API transports engine state and the UI displays it; do not copy Paydirt’s
  timing values or rules.
- Define and document mode behavior at possession changes, kicks, timeouts,
  halftime, period transitions and game completion before implementation.
  Persistence must never bypass a required decision or authorize an illegal play.
- Turning the mode on/off alone must not consume dice, execute a play, spend a
  timeout or charge clock time. Preserve expiration safeguards and prevent
  stacked timing reductions.
- Add synthetic engine/API/UI regressions for default-off, enable, consecutive
  eligible plays, disable, boundary/reset policies and hurried penalty behavior.
  Verify keyboard accessibility and visible on/off state in the browser.
