## Description

A scoring play currently updates the engine-owned score and commentary without a distinct visual celebration, making touchdowns, conversions, safeties, and field goals easy to miss during browser play.

## Resolution / verification

- Animate only after an engine report records points, using engine-provided score and scoring data rather than frontend football inference.
- Respect reduced-motion preferences and never delay, block, or alter legal engine actions, clocks, dice, saves, or API responses.
- Add frontend tests for score-triggered presentation and reduced-motion behavior, then verify the production build.
