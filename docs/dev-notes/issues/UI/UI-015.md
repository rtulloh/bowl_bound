## Description

The user suggests tooltips that briefly explain each offensive play and defensive
formation, helping human players understand the numbered and lettered choices.

## Resolution / verification

- Provide concise original descriptions for all nine supported offensive plays and
  six defensive formations. Explain their broad purpose and relevant Bowl Bound
  distinctions without copying rulebook passages or presenting NFL assumptions.
- Supply help text through engine-owned action metadata. The API transports it and
  the frontend displays it; do not duplicate rule definitions in UI constants.
- Make help available on hover and keyboard focus, with a discoverable touch
  interaction. Do not rely solely on the HTML title attribute. Help must not
  accidentally select a play, snap the ball, change a choice, or consume dice.
- Keep short button labels, the selected state and the compact/mobile layout clear.
  Explanations must not reveal private chart entries or promise unsupported options.
- Cover the metadata contract, all descriptions, focus/hover/touch behavior and
  unchanged legal selections with synthetic engine/API/UI and browser tests.
