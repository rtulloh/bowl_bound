## Description

With the larger current play catalog, the desktop selector can extend below the viewport even after the result area is stabilized. Players must scroll the page before they can reach lower calls such as special plays.

## Resolution / verification

- Keep the latest result and dice above the selector while bounding that region to a compact height with internal overflow for exceptional detail.
- Keep every legal play call visible without an internal selector scrollbar, using a compact responsive four-column desktop palette (and an appropriate narrower-screen layout).
- Add frontend regression coverage for the bounded result and selector panels, then verify the frontend suite and production build.
