## Description

PlayReport.commentary is a property so asdict never serializes it; the browser shows description while the CLI prints commentary, so the two adapters print different text for the same play. PlayHighlights re-derives interception, fumble, touchdown, breakaway and touchback emphasis from outcome codes, statistics kind, trace section strings and timing flags, duplicating engine classification in presentation.

## Resolution / verification

- View exposes commentary and structured highlight tags from the engine; browser renders them without classification logic; CLI and browser text match for a synthetic game; no-rules scan extended to trace section strings.
