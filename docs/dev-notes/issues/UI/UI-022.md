## Description

The compact dice line used pale slate text on a light panel, measuring only
1.13:1 contrast. A synthetic fumble-to-touchback report also demonstrates how
a short terminal description hides the preceding event without visual cues.
Owner requested emphasis for fumbles, interceptions, touchdowns and breakaways,
and explicitly constrained this work to UI-only changes.

## Resolution / verification

- Inherit the panel's dark text for compact dice; browser contrast must be >=4.5:1.
- Add high-contrast, textual event badges in the result and historical log.
- Use only existing structured outcome/statistics/trace-section facts. No
  prose/raw-cell parsing, yardage thresholds, rule calculations or new API facts.
- Label pending interception as a decision, preserve touchback/fumble distinction,
  and identify a consulted breakaway roll without claiming a resulting big gain.
- Keep engine/backend, chart bundles, saves, dice and pending decisions unchanged.
- Keep the live game running; deploy only rebuilt static frontend assets.
