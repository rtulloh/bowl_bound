## Description

After a computer touchdown, a human defender can receive the ordinary defensive-formation prompt for a two-point try. The selected formation is correctly used for the conversion, but an automatic computer kickoff immediately replaces its result in the main panel. This makes the defense selection appear to have triggered a kickoff and obscures whether the try succeeded.

## Resolution / verification

- Announce the computer's two-point decision in engine-owned commentary before asking the human to choose a defense, for example, "Cedar Valley is going for two. Choose your defense." Keep the announcement visible while awaiting that selection and retain it in the copyable play history; a phase label or generic defensive prompt alone is insufficient.
- Use engine-provided phase and ownership to identify a two-point defensive selection explicitly; retain hidden computer calls.
- Announce whether the conversion succeeded or failed before presenting the following kickoff result; preserve the ordered announcements in complete play history.
- Keep the completed conversion result clearly reviewable when an automatic kickoff follows, with distinct ordered conversion and kickoff outcomes and complete play history.
- Cover successful and failed two-point tries, both human sides, automatic kickoff or required return decisions, and end-of-game transitions with synthetic engine/API/frontend tests before production changes. Assert that the attempt announcement is visible before the human defense submission and that ordered commentary remains available after the automatic kickoff.
