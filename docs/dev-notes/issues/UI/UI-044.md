## Description

The browser renders Razzle-Dazzle's two possible dice totals as one long, unevenly wrapped sequence of generic decision buttons. Repeated play numbers are unexplained and a no-change chart cell renders as a blank value after the colon, which looks like missing data rather than a zero-yard choice.

## Resolution / verification

- Present the engine-offered Razzle-Dazzle choices in a stable, aligned matrix grouped by play with one labeled column per available total.
- Use an explicit player-facing zero for a no-change Razzle-Dazzle outcome while preserving the chart/export token and engine semantics.
- Keep generic penalty, return, conversion, and toss choices unchanged; add focused frontend and engine/API tests.
