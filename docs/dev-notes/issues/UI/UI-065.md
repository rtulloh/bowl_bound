## Description

Owner uses multiple displays and wants chart placement under their control.
Offer Open in new tab and Open in separate window alongside the in-game viewer.
Detached views keep their own team and Offense / Defense / Priority controls and
can remain open on another display while the user plays in the main game.

## Resolution / verification

- Both launch options open a usable read-only view tied to the existing match.
- Offense/defense values come from the same loaded CSV facts used by that game; Priority uses the shared engine matrix.
- Detached navigation never creates a game, submits a play, prepares a computer turn, consumes dice or changes the save/revision/clock/pending decisions.
- The main game remains usable while the detached view stays open.
- Browser controls support window movement/resizing; handle blocked launches and expired sessions accessibly.
- Keep reading help initially closed and verify desktop/phone presentation and safe window opening in browser tests.
