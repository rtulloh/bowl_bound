## Description

After ordinary plays the clock choices occupy five full-sized button rows,
followed by empty offense, defense, special-teams and game-action panels.
This overwhelms the result and forces an explicit-looking choice for routine play.

## Resolution / verification

Use Paydirt’s optional-modifier presentation without copying its timing rules.
Default to None alongside usable play controls; normal next snaps require no
clock confirmation. Intentionally clicking a timeout, hurry-up or spike applies
that engine decision once. Keep explicit Continue only when normal timing ends
the period, preserving the opportunity to save time. Verify desktop/mobile bounds,
normal continuation, modifiers, disabled choices and repeated clock windows.
Football decisions remain blocking; engine-owned period transitions use no new dice.
