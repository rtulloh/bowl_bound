## Description

The browser currently combines persistent hurry-up mode, timeout and clock radios, advanced in-bounds/out-of-bounds declarations, and short OOB/IB buttons in one unlabeled row. A selected bounds declaration has no obvious visual confirmation, so a player cannot tell whether it applied before selecting a play.

## Resolution / verification

- Group modifiers by purpose with clear, player-facing labels and preserve engine-owned offered actions and availability.
- Show a visible selected state and concise consequence for an active in-bounds or out-of-bounds declaration; selecting it again clears it when the engine supports that behavior.
- Add browser unit coverage that exercises the API action and confirms selected/cleared state, then verify frontend tests and production build.
