## Description

On a browser game using synthetic teams, selecting an offensive play replaces the short pre-play result guidance with a variable-height outcome, dice display, and optional trace before the play selector. The selector shifts vertically between snaps, making repeated play selection harder.

## Resolution / verification

- Add a frontend regression test that verifies the play-control region has a stable reserved layout before and after a representative resolved play.
- Keep the result, dice, and detailed audit available without interpreting engine data in the UI.
- Verify the browser layout on a standard desktop viewport and run the frontend unit/build checks.
