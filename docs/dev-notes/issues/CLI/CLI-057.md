## Description

A play and one or more penalty rerolls can each produce a distinct penalty. The terminal correctly offers enforcement for each assessed penalty, but identical labels such as two defensive 15-yard fouls are indistinguishable. Players cannot tell whether choices apply to the original penalty or a reroll penalty.

## Resolution / verification

- A synthetic play with multiple same-yardage penalties labels each enforcement option with an engine-provided penalty sequence or source context.
- The menu makes clear that accepting one penalty does not stack all listed penalties.
- Each option explains whether enforcement cancels the kick and replays the down,
  requires a kickoff re-kick, or is enforced on a completed return.
- Choice identifiers, engine enforcement, save replay, and dice consumption remain unchanged.
