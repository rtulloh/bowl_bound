## Description

The pending interception context subtracts raw downfield distance from the line of scrimmage without applying Basic VI-13(E)(i). With a synthetic offense at the opponent 18 and an interception distance of 55, the prompt reports 37 yards deep, although the turnover resolver correctly places the interception nine yards deep. The misleading prompt affects the defender deciding between incompletion and interception, while actual return arithmetic uses the normalized depth.

## Resolution / verification

- Verify goal-line, in-zone and beyond-end-line contexts for both possessions with synthetic charts.
- Display the actual nine-yard return origin for beyond-end-line interceptions; preserve scoring, safety distinctions, commands, dice and old saves.
