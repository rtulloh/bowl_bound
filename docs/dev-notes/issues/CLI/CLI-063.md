## Description

The menu offers a one-point PAT kick with K and a separate two-point conversion, but supplies no visible Enter default. Track this independently from CLI-055, which concerns the subsequent post-score kickoff. Evidence is reproduced by reading the current convenience-policy guard: required pending decisions have no recommendation and blank CLI input returns without an action.

- Supply the default through engine/coaching-owned legal-action guidance; CLI presentation must not duplicate football decisions or consume dice merely by rendering or inspecting help.
