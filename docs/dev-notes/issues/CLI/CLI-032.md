## Description

Owner prefers Paydirt-style contextual help with a title/separator, grouped plays, aligned bracketed keys and brief descriptions, special teams/actions and options, instead of a generic command tutorial plus raw call/kick/action syntax after every label. Use actual Bowl Bound names and legal options only; preserve explicit commands through a separate commands reference.

## Resolution / verification

- Test-first help output checks verify grouped running/option and passing plays or defensive formations, legal special/options sections and no generic command preamble or raw command suffixes.
- Keep required decision IDs actionable, legal-only shortcuts and Enter default semantics; commands reference remains available.
- No unsupported Paydirt rules/options or descriptions promising unavailable outcomes; document and run cumulative tests.
