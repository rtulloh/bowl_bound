## Description

Terminal commentary can label an interception returner as the kick returner because turnover narration reuses the kick-return roster role. An interception return must use a defender from the intercepting team; roster fallback must say defensive back rather than kick returner.

## Resolution / verification

- Synthetic commentary regressions use a defensive-back roster name for both home and away interception returns.
- Kickoff and punt returns continue to use the kick-return roster role.
- Missing defensive roster data uses a defensive-player generic label and never the kick-return label.
