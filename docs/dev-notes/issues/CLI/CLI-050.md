## Description

A public-safe synthetic fourth-down offensive-penalty sequence leaves the terminal status as 'Choose an offensive play and defensive formation' while the only legal controls are accept/decline penalty choices. The accepted offensive penalty correctly replays fourth down; the misleading status makes it appear that another scrimmage call is being requested before the decision.

## Resolution / verification

- Add a synthetic terminal regression for a pending penalty decision and assert that its status identifies the required penalty choice rather than a scrimmage call.
- Keep pending-choice ownership, legal controls, dice state, and the post-decision fourth-down replay unchanged.
