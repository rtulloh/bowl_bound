## Description

During the owner-requested timeout alias cleanup, a synthetic regular-game regression showed the coordinator automatically chooses normal runoff for computer offense before the human defender can call an engine-offered timeout. This consumes the legal window and leaves no T control. Defer ordinary optional runoff until the next committed snap while exposing only the human defenders own timeout. Retain computer-owned required choices and non-default clock modifiers, and reuse existing engine timing.

## Resolution / verification

- Human defense can call its offered T during optional normal runoff with exact state/dice parity against the engine timeout decision; no additional confirmation prompt is required.
- Human defense cannot choose the computer teams timeout or offensive hurry/spike; computer-owned required and non-default clock choices retain ownership.
- Submitting a defensive formation without timeout lets the existing engine apply normal timing exactly once; previews, invalid inputs and failed commands consume no dice or time.
- Update intentional coordinator/CLI expectations with synthetic test-first evidence and run relevant API/browser/save and cumulative checks.
