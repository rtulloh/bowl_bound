## Description

save and load with no path and call, choose and kick with no argument all fall through to the generic use-an-offered-command error. Full command words are case-sensitive although docs/cli.md says keys are case-insensitive. Untested: quit during a mid-game pending decision writes nothing; T with zero timeouts; T in a non-optional period-ending window; load while automatic_paused resets the pause; --load with mismatched installed charts exits 1 with the teams-do-not-match message; KeyboardInterrupt inside coach_step exits 130 with no half-recorded command.

## Resolution / verification

- Commit `80d67c8` makes command words case-insensitive while preserving path and
  choice-ID arguments, adds targeted missing-argument messages, and clarifies the
  input behavior in `docs/cli.md`.
- Added synthetic CLI tests for missing arguments, case behavior, quitting during
  a pending choice without saving, loading while paused, the halftime boundary
  without an offered timeout, startup chart-fingerprint mismatch, and interrupting
  a computer turn. The existing zero-timeout test also passes.
- Focused validation: 96 CLI, shortcut, timeout, and input-contract tests passed;
  Ruff check and format checks passed.
