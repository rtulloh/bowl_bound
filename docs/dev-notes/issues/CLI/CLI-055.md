## Description

After a scored field goal or touchdown, the terminal requires the scoring human team to kick off before the next scrimmage play, but Enter has no default even when normal kickoff is the ordinary continuation. Show K/Kickoff as the displayed default and let Enter submit it. Keep onside kickoff as an explicit alternative.

## Resolution / verification

- A synthetic post-score human-kicker fixture displays Default=K/Kickoff and Enter produces the same engine state, journal, and dice consumption as K.
- Opening/halftime choices, required receiving decisions, and two-sided manual controls still require explicit input.
- Onside kickoff remains offered but is never selected by the Enter default.
