## Description

Owner specifies an Easy CLI helper, on by default and toggled by Z at play selection. It is unavailable in Medium/Hard and does not imply a browser panel. Rank up to three callable offensive plays using exact dice-weighted plain numeric offensive chart cells only; exclude missing rows and all symbolic outcomes, including penalties, turnovers, breakaways and BLACK. First-down target is ceil(distance/2), second down ceil(0.7*distance), third/fourth ceil(distance), minimum one yard. Percentages and average yards are conditional on evaluated numeric mass, with evaluated chart coverage shown separately. Situational/clock tips are separate; defensive advice is situational, not adaptive CPU-call learning.

## Resolution / verification

- Easy helper is enabled by default, toggled read-only by Z at play selection; Medium/Hard cannot enable it, and no browser helper panel is added. ? still expands compact help and / shows stats.
- Synthetic tests cover first/second/third/fourth-down target rounding and minimum one yard, including second-and-seven target five and third-and-seven target seven.
- Display up to three callable plays with target-reaching percentage, positive-gain percentage, conditional average yards and exact dice-weighted numeric coverage; reject missing and symbolic cells without interpreting secondary rules.
- Coverage below 50 percent is marked limited and ranked behind better-supported estimates. Sparse perfect rates never imply guarantees; document that coverage is not a confidence interval and estimates are not full-engine conversion odds.
- Keep advice game/RNG neutral and opponent-call private; retain separate situational/clock tips and defensive situational advice without learning CPU calls. Document and validate save/resume preference semantics.
