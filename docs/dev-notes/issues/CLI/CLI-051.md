## Description

When the CPU offense evaluates fourth down, the terminal presents a generic human defensive-formation prompt before resolving the CPU action. Paydirt-style flow should immediately execute a CPU punt or field goal and request a human defense only if the CPU chose a scrimmage play.

## Resolution / verification

- Synthetic coached fourth-down tests prove CPU punt and field-goal decisions require no human defensive input.
- A CPU scrimmage decision still keeps the offense hidden and requests only an offered human defense.
- The terminal, API coaching turn, save replay, and no-hidden-choice contract remain consistent.
