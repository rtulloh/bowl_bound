## Description

At regulation end, the terminal currently reports only that the game is complete. Add a one-time final recap with score by quarter, final total and winner, scoring summary, and available team statistics. Paydirt is a presentation reference only; use Bowl Bound engine-owned data and do not add standings, NFL-only statistics, or CLI-derived football calculations.

## Resolution / verification

- Synthetic completed regulation games render one FINAL recap before the terminal offers inspection/save/quit, including quarter scores, total, and winner or tie.
- Scoring entries and team statistics come from engine-owned structured records; the terminal does not parse commentary or recompute results.
- Final recap is stable across save/resume and does not consume dice, change score/statistics, or replace the existing optional Hard call-history summary.
- The same engine-owned recap facts are available to the API/web presentation without duplicating game logic.
