## Description

Owner requests a CLI save picker, with bare load defaulting to opening the most recent save file. Currently bare load returns a generic invalid-command message while load PATH works. Add a documented explicit picker command alongside the newest-save default, preserving explicit-path loading and existing private save validation. This ticket records requested behavior only; no implementation is authorized by this ticket-creation request.

## Resolution / verification

- Bare load selects and opens the most recent eligible regular non-symlink save in private-data/saves, with documented recency ordering and deterministic tie-breaking; show the selected path.
- An explicit documented picker command lists eligible private saves with useful local labels and allows selection or cancellation without advancing gameplay.
- Keep load PATH behavior and terminal control-mode preservation; do not mutate gameplay or consume dice during discovery, inspection, cancellation or failed loading.
- Handle missing or empty save folders, symlink candidates, unreadable files and malformed newest saves with actionable messages; never silently load a different save after validation failure.
- Use synthetic tests first for newest selection, ties, picker selection/cancellation, invalid files and save-state/RNG parity; update CLI documentation and retain private save handling.
