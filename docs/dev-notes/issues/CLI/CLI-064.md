## Description

Owner play-testing found that the human kickoff action menu displays K/Kickoff and O/Onside kickoff without the numeric choices used by other decision menus. Add visible and accepted numeric alternatives to this menu. This is separate from CLI-055 Enter defaults and CLI-059 alignment of numbers already present.

## Resolution / verification

- Write synthetic failing display and command tests for a human-owned kickoff: show [1] [K] Kickoff and, when legal, [2] [O] Onside kickoff.
- Numeric, mnemonic and full-command selections must invoke the same engine-provided legal actions with identical state, journal and dice consumption.
- Derive available entries and numbering from legal engine actions; preserve K/O and avoid conflicts with offensive play numbers, unavailable options, computer-owned turns or manual input.
- Keep normal-kickoff Enter default behavior in CLI-055; adding numbers must not silently execute a kick or make onside kickoff a default.
- Update terminal shortcut documentation, run focused synthetic menu/input and relevant save/replay checks, then record a tested commit and owner play-test confirmation before resolution/closure.
