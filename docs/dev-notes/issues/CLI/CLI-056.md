## Description

The terminal can narrate a punt landing spot before presenting fair-catch versus return, but the required decision menu itself omits that field context. A player deciding between fair catch and return must see the engine-provided landing spot in the menu without calculating it from distance or relying on earlier scrolling output.

## Resolution / verification

- A synthetic in-field punt decision menu displays the engine-provided landing spot beside fair-catch and return choices.
- The CLI displays an engine-provided landing/depth fact and does not recalculate field position from chart cells or dice.
- Kickoff, touchback, end-zone, and pending-result menus retain truthful context without duplicating unavailable choices.
