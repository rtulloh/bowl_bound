## Description

Owner reports duplicate [TH] [T] labels for the same Cedar Valley timeout. Follow-up direction explicitly rejects home/away timeout aliases: remove TH and TA entirely. Human/computer mode uses T for the human team whether on offense or defense; manual mode uses TO/TD for the offensive/defensive teams. Play-plus-timeout suffixes remain unimplemented pending a separate syntax specification.

## Resolution / verification

- Human/computer help and prompts advertise one T timeout for the human team, on offense or defense, without redundant TH/TA aliases; preserve engine chooser ownership and legal availability.
- Manual mode uses clear offense/defense timeout selection (`TO`/`TD`); no `TH`/`TA` aliases are accepted or advertised.
- Explicitly specify and test the proposed 5T/AT behavior before implementing any suffix; reuse offered engine clock actions and do not guess timing, charge both teams or advance a play twice.
- Use synthetic test-first presentation/command checks and retain state/RNG neutrality for help, invalid input and unavailable timeouts.
