## Description

The terminal rejected a call with an appended timeout request such as `7T`. The owner supplied `7T` as the intended offense syntax; defense uses the corresponding `AT` form. Resolve the call through the ordinary engine flow and apply the requested timeout only when legal. Standard play timing advances automatically; a separate normal-runoff command is not required. If the timeout is unavailable, keep the play, apply its normal timing, and explain that no timeout was used.

## Resolution / verification

- Accept an appended `T` for a currently offered offensive call (`1T`–`9T`) or defensive formation (`AT`–`FT`), case-insensitively.
- Submit exactly one play and computer response; apply the timeout only when the engine permits it and use Bowl Bound timing.
- If no timeout is offered, keep the play, consume no timeout, apply normal play timing, and report that the request was unavailable.
- Remove normal runoff as a separate player action. Preserve standalone `T` only where the engine independently offers that control; invalid calls must not change game state or dice.
- Use synthetic tests, explain the syntax in requested help output without repeating it in routine status displays, and update player documentation.
