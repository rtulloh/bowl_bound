## Description

Owner used the CLI printed Resume command for a game launched with a custom generated --seasons directory. The hint omitted that directory, so the next invocation selected different local charts and correctly rejected the saved team fingerprints.

## Resolution / verification

- Write a synthetic regression proving printed resume commands retain a custom seasons root, including a path containing spaces.
- Print absolute save and selected seasons paths so the hint remains valid after changing directories; keep human, compact and trace options.
- Verify loading with the printed arguments uses the original chart fingerprints without weakening save validation; do not modify the owner save or charts.
