## Description

Decision-menu rows can place a variable-width mnemonic before their numeric shortcut, such as [FC] [1] beside [R] [2]. The numeric options then do not align vertically. Render decision numbers first so numbered choices form an easy-to-scan column without changing accepted shortcuts or command IDs.

## Resolution / verification

- Synthetic fair-catch/return and other multi-character mnemonic menus render consecutive numeric shortcuts in one aligned leading column.
- Mnemonic, numeric, and full-ID command handling remains unchanged.
