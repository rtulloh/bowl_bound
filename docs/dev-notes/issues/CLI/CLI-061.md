## Description

The shared commentary marker appends TURNOVER whenever state-after possession differs from state-before possession. On a kickoff return, that expected kicking-to-receiving possession change is not a turnover, even when the receiver fumbles and recovers its own return. Limit turnover emphasis to actual turnover facts rather than generic possession change.

## Resolution / verification

- Synthetic kickoff return, including an own-recovered return fumble, never renders the turnover marker.
- Interceptions, defensive fumble recoveries, and turnover-on-downs retain truthful turnover emphasis.
- Commentary uses structured engine outcome/trace facts and does not infer turnover status from prose or CLI field calculations.
