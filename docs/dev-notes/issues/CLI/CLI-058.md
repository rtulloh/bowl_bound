## Description

The terminal moves from the second quarter into the scheduled second-half kickoff without a distinct halftime announcement or a compact summary of the game so far. Add a one-time halftime presentation using Bowl Bound engine-owned score-by-quarter, scoring events, and available team statistics. Paydirt is presentation input only; do not copy NFL-specific fields, rules, or formatting.

## Resolution / verification

- Synthetic regulation games reaching halftime render one HALFTIME announcement before the second-half kickoff prompt, including score-by-quarter and first-half total.
- The summary lists engine-owned first-half scoring events and supported team statistics without parsing commentary or recalculating football results in the CLI.
- Halftime appears exactly once through direct play, pending decisions, and save/resume; it does not consume dice, time, or alter kickoff ownership.
- Cover a scoring play that exhausts Q2 followed by a computer-owned second-half kickoff: show the halftime announcement/summary before the automatic kickoff and return reports, even when there is no human kickoff prompt.
