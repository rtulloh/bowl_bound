## Description

The terminal used to show unavailable penalty-enforcement variants between enabled
choices. Even without a number, these implementation-only options cluttered the
menu and made a player scan choices they cannot make. Hide all disabled pending
choices in terminal menus; the engine remains authoritative for availability and
still rejects direct attempts to select a disabled identifier.

## Resolution / verification

- Terminal decision menus display only enabled choices, with no unavailable
  labels or reasons.
- Numeric shortcuts remain mapped only to enabled engine choices and do not change save/API choice identifiers.
- Direct numeric or full-ID attempts at a disabled choice remain rejected without
  advancing dice or game state.
