## Description

TerminalGame computes player_advice both when displaying the helper and when building the help menu, even when the helper is off. Untested: Z before the opening kick, during a required decision and after the game finished; helper visibility in the optional-runoff window; human-away offense using the away chart; all-symbolic charts giving zero coverage ordered by id; negative average rendering; more than three callable plays truncating after sorting; exhaustive 216-face target and positive rates for all nine plays; Medium run bias clamp and symbolic fallback; CLI text contains the disclaimers and never the word success.

## Resolution / verification

- Advice computed once per prompt and only when needed; each listed case has a synthetic test; saved facts unchanged in every case.
