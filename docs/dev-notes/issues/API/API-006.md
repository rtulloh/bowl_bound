## Description

Review of 5294eb8..44d3438 reproduced an unhandled validation exception. `Snap` accepts REDZONE syntactically, but `_parse_formation` in `session.py:2296-2299` raises plain ValueError when it is not offered. The manual snap endpoint catches InvalidDecisionError and ChartResolutionError, not ValueError.

Synthetic reproduction: create a normal drive using default_teams() and TestClient(create_app(root), raise_server_exceptions=False); POST /snap with play="1", defense="REDZONE" at own 35. Response is HTTP 500 "Internal Server Error", rather than a client validation response. The same mismatch can occur for advanced calls in a legacy six-defense game. Existing tests check offered calls but not forbidden calls at the HTTP boundary.

Assigned to milestone 23 after milestone 22 acceptance.

## Resolution / verification

- Raise the engine decision-validation exception for unavailable formations and map it to a safe 4xx response.
- Add HTTP tests for REDZONE at/above the 20 and Advanced II calls on a legacy six-defense game, asserting unchanged state and dice.
