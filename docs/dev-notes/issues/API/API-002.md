## Description

GET /api/games/{id}?human_side, POST /coach and POST /decision?human_side call coach_view, coach_step and coach_execute, which raise ValueError or NoLegalAction from plan_turn. None are caught, so the API returns 500 while docs/coaching.md promises an empty legal set fails clearly. Reproduced with a synthetic game and a patched coordinator.

## Resolution / verification

- Map coordinator ValueError and NoLegalAction to 409 or 422 with a stable message; tests for each endpoint; docs updated.
